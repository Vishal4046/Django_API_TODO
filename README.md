# Django Todo API

A Todo Management REST API built using **Python, Django REST Framework, and SQLite**. This project provides CRUD operations to create, retrieve, update, and delete tasks, with task status and due date management.

## Features

- Create new tasks
- Retrieve all tasks
- Retrieve a single task by ID
- Update task details
- Partially update task details
- Delete tasks
- Manage task status: Pending, In Progress, and Completed
- Set a due date for each task
- Store task data in SQLite
- Validate request data using Django REST Framework serializers

## Technologies Used

- Django

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Vishal4046/Django_API_TODO.git
cd Django_API_TODO
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install django djangorestframework
```

### 4. Apply database migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Start the development server

```bash
python manage.py runserver
```

The API will be available at:

`http://127.0.0.1:8000/`

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/getdata/` | Retrieve all tasks |
| POST | `/getdata/` | Create a task |
| GET | `/details/<id>/` | Retrieve a task by ID |
| PUT | `/details/<id>/` | Update a task |
| PATCH | `/details/<id>/` | Partially update a task |
| DELETE | `/details/<id>/` | Delete a task |

## Sample JSON Request

Send a POST request to `/getdata/` with the following JSON body:

```json
{
  "title": "Learn Django REST Framework",
  "description": "Practice API development and CRUD operations",
  "status": "Pending",
  "due_date": "2026-10-30"
}
```

### Sample JSON Response

```json
{
  "id": 1,
  "title": "Learn Django REST Framework",
  "description": "Practice API development and CRUD operations",
  "status": "Pending",
  "due_date": "2026-10-30",
  "created_at": "2026-10-23T12:00:00Z"

```

*Note: The ID and creation timestamp are generated by the application. The response is an example.*

## HTTP Status Codes

- `200 OK` — Request successful
- `201 Created` — Task created successfully
- `204 No Content` — Task deleted successfully
- `400 Bad Request` — Invalid request data
- `404 Not Found` — Task does not exist
